# Reading the Voice Studio code

Start with `src/App.tsx` for the workspace, then follow `src/voices/VoiceStudio.tsx` → `voice-engine.ts` → `public/audio-runtime/speech-inference.worker.js`. Each authored module has a purpose comment, and named functions explain the job they perform. Lifecycle callbacks have comments where cancellation, cleanup or event ordering matters.

## Voice workflow names

| Function or method | Use case |
| --- | --- |
| `getOrCreateVoiceEngine` | Reuse a worker for the chosen model bundle. |
| `cloneAndSaveVoiceProfile` | Turn a reference into a durable library entry. |
| `startReferenceRecording` | Capture microphone audio for cloning. |
| `generateAndPlaySpeech` | Generate, stream playback and prepare a download. |
| `cancelActiveVoiceOperation` | Cancel pending UI work and release inference/playback resources. |
| `renameSavedVoiceProfile` / `deleteSavedVoiceProfile` | Handle library edits from React. |
| `loadSavedVoiceProfiles` / `persistVoiceProfile` / `deleteVoiceProfile` | Read or commit IndexedDB records. |
| `sendWorkerRequest` | Wait for the completion message for one worker command. |
| `encodePcmChunksAsWav` | Convert generated PCM into a local downloadable WAV. |
| `createStreamingAudioPlayer` | Load and initialize the audio-thread playback bridge. |
| `enqueueAudioChunk` / `flushQueuedAudioChunks` | Feed PCM into the worklet as buffer capacity permits. |
| `finishAudioStream` | Flush the final samples, including very short streams. |
| `releasePlaybackResources` | Disconnect the old player when stopping or replacing playback. |

The engine's public `initialize`, `cloneVoice`, `synthesize` and `dispose` methods retain the requested reusable API. Browser-defined methods such as AudioWorklet `process`, IndexedDB `transaction`, MediaRecorder `stop`, and event-listener methods keep their platform conventions. Worker message strings, database names and stored profile fields are unchanged so existing saved voices remain compatible.
